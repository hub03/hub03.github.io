# 🏙️ Mini-Ville

Prototype HTML/CSS/JS d'un mini city-builder minimaliste.

## Jouer

Ouvre `index.html` dans un navigateur, ou publie le dossier sur GitHub Pages.

## Commandes

- Cliquer une case vide : construire
- Cliquer un bâtiment : voir ses statistiques
- ⏸ Pause / ▶ 1 tour
- 🗺️ Agrandir : acheter une extension
- ↻ Recommencer : effacer la sauvegarde

La partie est sauvegardée automatiquement dans `localStorage`.

## Déploiement GitHub Pages

1. Créer un dépôt GitHub.
2. Ajouter `index.html`, `style.css`, `script.js` et ce README.
3. Aller dans **Settings → Pages**.
4. Choisir le déploiement depuis la branche principale (`main`) et le dossier `/root`.
5. GitHub fournira l'URL de la page.

## Prochaine étape

Le prototype est volontairement simple. Les données des bâtiments et les règles sont centralisées au début de `script.js`, afin de faciliter l'équilibrage.
