# Pointage PWA

Application statique HTML/CSS/JS, prévue pour GitHub Pages.

## Mise en ligne
1. Créer un dépôt GitHub.
2. Copier tous les fichiers de ce dossier à la racine du dépôt.
3. Activer GitHub Pages sur la branche principale / dossier racine.
4. Ouvrir l'URL HTTPS de GitHub Pages.

Les données sont stockées localement dans IndexedDB. Une sauvegarde JSON est disponible dans le menu.

Historique initial intégré : 14/07/2026 → 14/08/2026.
